# Архітектура AI-агента (Build Engineer)

## 1. Проблеми, які вирішує агент
- Автоматизація створення структури Rust-проєкту.
- Налаштування системи складання та локальних тестів (`cargo test`).
- Створення кросплатформного CI/CD workflow (GitHub Actions) для Windows, Linux, macOS.
- Перевірка відсутності секретів та сміттєвих файлів у репозиторії.

## 2. Skills (Навички)
- `project-scaffold`: створює базову структуру проєкту та .gitignore.
- `build-and-test`: створює сирцевий код, тести та кросплатформні скрипти збірки (`ci.sh`, `ci.bat`).
- `github-actions`: створює workflow `.github/workflows/ci.yml`.

## 3. Commands (Команди)
- `git-init`: перевірка стану Git та .gitignore.
- `create-project`: виклик `project-scaffold`.
- `create-build`: виклик `build-and-test`.
- `create-actions`: виклик `github-actions`.
- `check`: перевірка працездатності та цілісності проєкту.
- `init`: оркестратор, що запускає всі команди послідовно.

## 4. Обробка помилок
Якщо будь-який крок викликає помилку (наприклад, не проходить `cargo test`), оркестратор зупиняє виконання та виводить повідомлення про помилку.
